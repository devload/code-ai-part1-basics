## 🎯 학습 목표

**AI가 프롬프트를 받아 응답을 생성하기까지의 내부 과정을 이해합니다**

```
사용자: "오늘 날씨 어때?"
        │
        ▼
┌─────────────────────────────────────────────────────────┐
│ STEP 1: 토큰화                                           │
│ "오늘 날씨 어때?" → [오늘] [날씨] [어때] [?]              │
└─────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────┐
│ STEP 2: 컨텍스트 구성                                    │
│ [시스템 프롬프트] + [히스토리] + [사용자 입력]            │
└─────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────┐
│ STEP 3: 확률 계산 (N-gram)                               │
│ 다음 토큰 후보: "좋다"(35%), "맑다"(25%), "흐리다"(20%)...│
└─────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────┐
│ STEP 4: 샘플링                                           │
│ Temperature, Top-k, Top-p 적용 → "좋다" 선택             │
└─────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────┐
│ STEP 5: Embedding (토큰 → 벡터)                          │
│ "날씨" → [0.12, -0.34, 0.56, ...] (64차원 벡터)          │
└─────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────┐
│ STEP 6: Transformer (Self-Attention)                     │
│ 문맥 파악: "오늘" + "날씨" → 관계 학습                    │
└─────────────────────────────────────────────────────────┘
        │
        ▼
AI: "오늘 날씨 좋다고 생각해요!"
```

## 📚 학습 단계 (STEP 1-8)

| STEP | 제목 | 핵심 질문 | 실행 명령 |
|------|------|----------|----------|
| 1 | 토큰화 | 왜 문장을 조각내는가? | `./gradlew :step1-tokenization:run` |
| 2 | 컨텍스트 | AI는 뭘 보고 답하는가? | `./gradlew :step2-context:run` |
| 3 | 확률 계산 | 다음 단어를 어떻게 예측하는가? | `./gradlew :step3-probability:run` |
| 4 | 샘플링 | 왜 매번 답이 다른가? | `./gradlew :step4-sampling:run` |
| 5 | **Embedding** | 단어를 숫자로 어떻게 표현하는가? | `./gradlew :step5-embedding:run` |
| 6 | **Transformer** | AI가 문맥을 어떻게 이해하는가? | `./gradlew :step6-transformer:run` |
| 7 | 생성 루프 | 한 번에 쓰는가, 한 글자씩 쓰는가? | `./gradlew :step7-generation:run` |
| 8 | 후처리 | 왜 가끔 거절하는가? | `./gradlew :step8-postprocess:run` |

## 🚀 빠른 시작

### 빌드
```bash
./gradlew build
```

### 데모 실행
```bash
# Embedding 데모 (토큰 → 벡터, 유사도 검색)
./gradlew :step5-embedding:run

# Transformer 데모 (Self-Attention, Position Encoding)
./gradlew :step6-transformer:run

# 전체 파이프라인 데모
./gradlew :pipeline:run
```

### 출력 예시 (Embedding)
```
[ 유사 단어 검색 ]
'강아지'와(과) 유사한 단어:
  - 고양이 (유사도: 0.841)
  - 햄스터 (유사도: 0.841)
  - 토끼 (유사도: 0.822)
```

### 출력 예시 (Transformer)
```
[ Self-Attention ]
문장: "강아지가 사료를 먹었다"

Attention 가중치:
              강아지가   사료를   먹었다
  강아지가:    0.415     0.357    0.228
   사료를:    0.266     0.514    0.219
   먹었다:    0.267     0.345    0.388
```

## 💡 핵심 개념

### Embedding
```
토큰 → 벡터 (고차원 공간의 점)
"왕" - "남자" + "여자" ≈ "여왕"
```

### Self-Attention
```
각 토큰이 다른 모든 토큰을 "참조"
"그것" → "강아지"를 가리킴을 이해
```

### Position Encoding
```
순서 정보 추가 (Transformer는 순서를 모름)
sin/cos 함수로 위치 인코딩
```
